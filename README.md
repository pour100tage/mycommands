# Mycommands
Is a comprehensive administration and utility script for FiveM, designed to simplify the management of vehicles, players, and the server environment.

Developed by **3ro.re**, this script offers a suite of fast and efficient tools accessible via chat commands, allowing complete control over gameplay without having to navigate complex menus.

## ✨ Features
The script is divided into three main categories of tools:

`/car` Spawns a vehicle                          |             `[model]` (e.g., adder)

`/dv` Deletes the current or nearest vehicle

`/repair` Instantly repairs the vehicle

`/boost` Increases engine power                  |             `[multiplier]` (max 200)

`/maxmods` Applies all max upgrades and turbo

`/flip` Rightes a flipped vehicle

`/clean` Cleans all dirt from the vehicle

`/plate` Changes the license plate               |             `[text]` (max 8 characters)

## 👤 Player Utilities

`/heal` Fully heals the player.

`/armor` Provides full body armor.

`/tpm` Teleports the player/vehicle to the waypoint.

`/coords` Displays the current coordinates (X, Y, Z, H).

## ⚙️ Administration & System

`/pingserver` Displays the player's current latency.

`/time` Changes the server time (Admin only) | `[time 0-23]`

`/weather` Changes the server weather (Admin only) | `[type]` (e.g., RAIN, EXTRA SUNNY)

## 🚀 Installation

1. Download: Clone this repository or download the glyph folder.
2. Placement: Place the folder in the resources directory of your FiveM server.
3. Activation: Add the following line to your `server.cfg` file.

Bash = `ensure mycommands`
